✿ PRÁCTICA N2 – GIT, GITHUB Y HTML ✿

1. ¿Qué es Git y cuál es su función principal dentro de un proyecto de desarrollo?

Respuesta: Git es un sistema que permite controlar las diferentes versiones de un proyecto. Su función principal es registrar los cambios realizados en los archivos y facilitar el trabajo durante el desarrollo.

2. ¿Cuál es la diferencia entre Git y GitHub y qué función cumple cada uno?

Respuesta: Git es el programa que permite administrar las versiones de un proyecto de forma local. GitHub es un servicio en línea que permite guardar repositorios y colaborar con otras personas.

3. ¿Qué pasos se deben seguir en Git para guardar los cambios realizados en un proyecto y crear un commit?

Respuesta: Primero se comprueban los archivos modificados, luego se agregan los cambios al área de preparación y finalmente se crea un commit con un mensaje que describa los cambios.

  1. Comprobar los cambios.
  2. Usar git add.
  3. Crear el commit con git commit.

4. ¿Qué comandos se utilizan para conectar un repositorio local con un repositorio de GitHub y posteriormente subir los cambios?

Respuesta: Para conectar el repositorio local se puede utilizar git remote add origin. Después, para enviar los cambios al repositorio de GitHub se utiliza git push.

  • git remote add origin
  • git push

5. ¿Qué es una rama (branch) en Git y en qué situaciones puede ser útil trabajar con una rama diferente a main?

Respuesta: Una branch es una versión independiente del trabajo dentro del repositorio. Se puede utilizar para probar nuevas funciones, corregir errores o realizar modificaciones sin afectar directamente a main.

6. Explique el proceso para crear una nueva rama, realizar cambios en ella y posteriormente subir esa rama a un repositorio de GitHub.

Respuesta: Se crea una rama nueva y se cambia a ella. Luego se realizan las modificaciones necesarias, se agregan los archivos y se guarda el trabajo mediante un commit. Finalmente, se utiliza git push para enviar la rama a GitHub.

  1. Crear una nueva rama.
  2. Cambiar a la nueva rama.
  3. Modificar los archivos.
  4. Agregar los cambios.
  5. Crear un commit.
  6. Subir la rama a GitHub.

7. ¿Qué es un conflicto en Git y qué pasos se deben seguir para resolverlo antes de combinar los cambios de una rama con main?

Respuesta: Un conflicto aparece cuando dos cambios diferentes afectan una misma parte de un archivo. Para solucionarlo se debe abrir el archivo, revisar las opciones que muestra Git, dejar el contenido correcto, guardar los cambios y realizar un nuevo commit.
