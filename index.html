Guía para usar GitHub

Alumna:ABIGAIL ALVAREZ PUITA

1) Crear una cuenta en GitHub

  1. Abrir la página de GitHub.
  2. Hacer clic en Sign up.
  3. Colocar nuestro correo electrónico.
  4. Crear una contraseña.
  5. Elegir un nombre de usuario.
  6. Realizar la comprobación que pide GitHub.
  7. Confirmar la cuenta desde el correo.
  8. Entrar a nuestra cuenta.

2) Hacer un repositorio

  1. Iniciar sesión en GitHub.
  2. Buscar el signo + y hacer clic.
  3. Seleccionar New repository.
  4. Colocar el nombre del repositorio:

aux-sis313g1-i26-AlvarezPuita_Abigail

  1. Agregar una pequeña descripción.
  2. Marcar Public.
  3. Dejar las otras opciones sin cambiar.
  4. Hacer clic en Create repository.

3) Enviar archivos a GitHub

Abrimos Visual Studio Code y la terminal.

Primero descargamos el repositorio:

git clone URL_DEL_REPOSITORIO

Después entramos a la carpeta:

cd nombre-del-repositorio

Comprobamos si existen cambios:

git status

Seleccionamos los archivos:

git add .

Guardamos los cambios:

git commit -m "Cambios realizados"

Finalmente los enviamos a GitHub:

git push

4) Publicar la página con GitHub Pages

  1. Entrar al repositorio creado.
  2. Ir a Settings.
  3. Buscar la opción Pages.
  4. En Source elegir Deploy from a branch.
  5. Seleccionar la rama main.
  6. Elegir la carpeta /(root).
  7. Guardar los cambios con Save.
  8. Esperar a que termine la publicación.
  9. Entrar en Visit site para ver la página.

De esta manera nuestra página queda publicada en Internet.
